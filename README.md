# 🏖️ Aura Ceylon Resorts - Luxury Hotel & Villa Reservation System

A full-stack luxury hospitality booking management application powered by Next.js, React, TypeScript, and Supabase.

[![Live Demo](https://img.shields.io/badge/Live_Demo-View_App-06b6d4?style=for-the-badge)](https://demo-proejct-3.vercel.app/)

---

## 📖 Overview
A resort management and booking portal tailored for the Sri Lankan hospitality market, featuring real-time room availability, interactive stay calculators, and user authentications.

## ✨ Key Features
- **User Authentication:** Email/Password auth powered by Supabase Auth.
- **Dynamic Booking Calculator:** Instant LKR rate calculation based on check-in/out dates and guest count.
- **Reservation Tracker:** Real-time dashboard for users to track booking status (Confirmed, Pending, Cancelled).
- **Localized Content:** Fully configured with Sri Lankan locations, Sri Lankan Rupee (LKR) currency formatting, and authentic property layouts.
- **Animated UI:** Powered by smooth Framer Motion micro-interactions.

## 🛠️ Tech Stack
- **Frontend:** Next.js, React, TypeScript, Tailwind CSS, Framer Motion
- **Backend & Database:** Supabase (Auth, PostgreSQL DB, Row Level Security)
- **Deployment:** Vercel
